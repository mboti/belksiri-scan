支持

联系方式：mboti.dev@gmail.com

联系我们

如对 Belksiri Scan 有任何问题、故障或建议，请发送邮件至 mboti.dev@gmail.com。请注明您的设备（iPhone、iPad 或 Mac）、其系统版本，以及在设置 › 关于中显示的应用版本。

在 Windows 电脑上，请注明您的 Windows 版本和应用版本。

Belksiri Scan Pro

iPhone、iPad 和 Mac

  • 购买：打开 Pro 优惠页面（Pro 按钮，或设置 › 升级到 Pro），然后点击“购买”。价格以 App Store 显示的价格为准。
  • 恢复：在登录同一 Apple 账户的另一台 iPhone、iPad 或 Mac 上，或在重新安装后，打开 Pro 优惠页面并选择恢复购买。
  • 等待批准：如果购买需要批准（购买前询问）或付款确认，Pro 将在 App Store 确认后立即激活。
  • 退款：退款由 Apple 通过 reportaproblem.apple.com 处理。

Windows

  • 购买：打开 Pro 优惠页面（Pro 按钮，或设置 › 升级到 Pro），然后点击“购买”。购买由 Microsoft Store 处理，价格也由其显示。
  • 恢复：在 Microsoft Store 中使用同一 Microsoft 账户的另一台 Windows 电脑上，或重新安装后，打开 Pro 优惠页面并选择恢复购买。
  • 等待确认：Microsoft Store 确认许可证后，Pro 随即激活。
  • 退款：退款由 Microsoft 处理。
  • Apple 与 Windows 相互独立：在 App Store 的购买不适用于 Windows，在 Microsoft Store 的购买也不适用于 iPhone、iPad 或 Mac。

准备 ESP32-C5 开发板

在 iPhone 和 iPad 上，Belksiri Scan 需要已安装固件的 ESP32-C5 开发板。请在 Mac 或 Windows 电脑上使用 Belksiri Firmware Installer 通过 USB 安装：下载与说明。

在 Windows 电脑上，开发板为可选：电脑本身通过其 Wi-Fi 适配器扫描 Wi-Fi。如果 Windows 拒绝扫描，请检查设置 › 隐私和安全性 › 位置。闪存不小于 4 MB 的开发板可通过蓝牙 LE 用作外部测量来源。其固件有两种安装方式：通过 USB 从 Belksiri Scan 安装，或使用 Belksiri Firmware Installer，这是一款免费的独立实用工具，无需 Belksiri Scan 即可准备开发板。该工具的 Windows x64 版本是未签名的预览版：已测试的内容请见下载页面。
