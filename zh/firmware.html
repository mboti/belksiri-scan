准备 ESP32-C5 开发板

在 iPhone 和 iPad 上，Belksiri Scan 通过 ESP32-C5 开发板进行测量。要为开发板安装固件，请用 USB 将其连接到电脑，并使用免费的独立工具 Belksiri Firmware Installer：该电脑上无需 Belksiri Scan、账户、互联网连接或开发工具。

此版本的状态

  • 预览版，适用于 Apple 芯片 Mac、Intel Mac 和 Windows x64 电脑。
  • Apple 芯片 Mac：已使用 Developer ID 签名并经 Apple 公证。USB 安装已在真实开发板上验证：一块 ESP32-C5（4 MB，CH340 USB 转换器）已完成烧录和逐字节回读校验，固件已启动。尚待确认：此次安装后从 iPhone 或 iPad 上的 Belksiri Scan 进行连接和扫描。
  • Intel Mac：已使用 Developer ID 签名并经 Apple 公证。仅在 Apple 芯片 Mac 上通过 Rosetta 启动过：未在 Intel Mac 上试用，未测试 USB 安装。
  • Windows x64：未签名（没有 Authenticode 证书）。已在 GitHub Actions 的 Windows 机器上编译、通过模拟开发板测试并启动：未在真实电脑上试用，未测试 USB 安装。
  • 工具语言：仅英语，与本页语言无关。因此下文引用的界面文字均为英语，与屏幕显示一致。

前提条件

  • macOS 12 或更高版本，或 Windows 10/11 x64。
  • 闪存不少于 4 MB 的 ESP32-C5 开发板。任何其他芯片，或闪存更小、无法读取的开发板，都会在写入前被拒绝。
  • 可传输数据的 USB 线：很多线只能充电。
  • USB 驱动：ESP32-C5 的原生 USB 接口无需驱动。带 CP210x 或 CH340 转换芯片的开发板仅在 Windows 上需要该芯片厂商的驱动。

适用于 ESP32-C5 的 ESP Device Studio 1.0.4（ESP-IDF v5.5.4）。镜像的 SHA-256：83de9994a710dba224c7ccb0248bb4e2334af38ce3e32e818c5d0cba66a9a499，写入前由工具校验。内含未经修改的烧录工具 espflash 4.5.0（MIT 和 Apache-2.0 许可）。

首次打开应用

Mac

  1. 打开 .dmg 文件，将 Belksiri Firmware Installer 拖到应用程序。
  2. 打开应用并确认：对于下载的应用，macOS 只会询问一次。

Windows

  1. 完整解压 ZIP 文件（便携版，无需管理员权限），然后运行 BelksiriFirmwareInstaller.exe。
  2. 由于文件未签名，首次启动时 SmartScreen 会显示警告。请先核对校验值，再仅对此应用选择“更多信息”和“仍要运行”。

安装固件

  1. 用可传输数据的 USB 线将 ESP32-C5 开发板连接到电脑。
  2. 检查开发板一行：ESP32-C5 (rev v1.0) · 4 MB flash Compatible。如连接了多块开发板，请选择其中一块。
  3. 点击 Install firmware 并确认。
  4. 等待显示 Firmware installed and verified。操作期间请勿拔下开发板或关闭窗口。
  5. 在 iPhone 或 iPad 上打开 Belksiri Scan，通过蓝牙连接开发板。

会被清除的内容：开发板上保存的设置，包括其 Wi-Fi 网络和密码。确认对话框会提示这一点。“Verified”表示已回读开发板且与镜像一致；随后从 Belksiri Scan 连接即可确认固件正在运行。

如果开发板没有响应

按住 BOOT 键，按下并松开 RESET，松开 BOOT，然后点击 Try again。出错时，Copy details 会复制一份报告，可附在发给 mboti.dev@gmail.com 的邮件中。
