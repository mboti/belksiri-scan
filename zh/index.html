WiFi Analyzer Diag

测量。绘图。诊断。

原名 Belksiri Scan。

在 iPhone、iPad、Mac 和 Windows 上进行 Wi-Fi 扫描、网络测试，并在您的平面图上进行覆盖勘测。

了解 WiFi Analyzer Diag 隐私政策

功能

从您身边的无线信号，到可直接交付的报告

  • 扫描

    您周围的网络及其接入点（BSSID）、信号、信道、频段和安全类型，以及每个接入点的制造商——取自应用内置的数据库。

  • 诊断

    Ping 您的路由器、公共解析器或任意地址；查看延迟、抖动和丢包；将本地网络与公共目标进行对比。

  • 勘测

    导入平面图，放置您的接入点，然后逐点测量。覆盖地图会显示哪里信号强、哪里信号不强。

  • 您的 ESP32-C5 开发板

    通过蓝牙配置它，并将其用作测量源。在 Mac 上，可通过 USB 为其安装固件。

  • WiFi Analyzer Diag Pro

    每个项目可包含多个楼层和多个接入点，并提供勘测分析、项目报告导出和状态诊断。一次性购买，无订阅。

  • 您的数据归您所有

    无需账户，没有广告，没有分析统计。项目保存在您的设备上；网络测试仅在您使用时才会连接公共服务。

平台

适用于

iPhone、iPad 和 Mac：购买一次 Pro，即可在使用同一 Apple 账户的三种设备上解锁。

Windows：应用和 Pro 均可在 Microsoft Store 获取。在 Windows 上购买的 Pro 与您的 Microsoft 账户关联，与在 App Store 的购买相互独立。

  • iPhone 和 iPad

    扫描和勘测测量需使用 ESP32-C5 开发板：iOS 不允许应用扫描 Wi-Fi 网络。

    App Store

  • Mac

    Mac 本身即可扫描 Wi-Fi；ESP32-C5 开发板为可选。

    App Store

  • Windows

    电脑使用自身的 Wi-Fi 适配器扫描；Windows 可能会请求位置访问同意。

    Microsoft Store
