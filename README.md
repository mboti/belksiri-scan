# Belksiri Scan — public pages

The public pages of Belksiri Scan: home, Privacy Policy, Terms of Use and
Support, in nine languages. Plain static HTML, no build step on the host, no
JavaScript, no web font, no CDN, no analytics, no cookie. They work opened
straight off a disk, which is how to review them before publishing.

Generated by `site/belksiri-scan/build.py` in the application's repository;
edit the sources there, never these files.

## Where they are published

A GitHub Pages **project site**, from the public repository `belksiri-scan`
under the account `mboti`, served from the root of its `main` branch - the
same arrangement as `mboti/markdown-one`.

| Page | Address |
|---|---|
| Home | `https://mboti.github.io/belksiri-scan/` |
| Privacy | `https://mboti.github.io/belksiri-scan/privacy.html` |
| Terms | `https://mboti.github.io/belksiri-scan/terms.html` |
| Support | `https://mboti.github.io/belksiri-scan/support.html` |

Each other language sits in its own folder: `https://mboti.github.io/belksiri-scan/fr/privacy.html`,
`de/`, `es/`, `it/`, `pt/`, `ru/`, `ar/`, `zh/`.

## How to publish

```sh
cd site/belksiri-scan && python3 build.py
cp -R public/. ../../../../belksiri-scan/
cd ../../../../belksiri-scan
git add -A && git commit -m "Update the public pages" && git push
```

`.nojekyll` stops GitHub running the files through Jekyll.

## What is deliberately not here

No source code, no project, no floor plan, no network name, no password, no
secret, no store button and no price: the price comes from the App Store, in
the reader's currency.
