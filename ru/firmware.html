Подготовка платы ESP32-C5

На iPhone и iPad Belksiri Scan проводит измерения с помощью платы ESP32-C5. Чтобы установить её прошивку, подключите плату по USB к компьютеру и используйте Belksiri Firmware Installer — бесплатную автономную утилиту: на этом компьютере не нужны ни Belksiri Scan, ни учётная запись, ни подключение к интернету, ни инструменты разработчика.

Состояние этой версии

  • Предварительная версия для Mac на Apple silicon, Mac с Intel и ПК с Windows x64.
  • Mac на Apple silicon: подписана Developer ID и нотаризована Apple. Установка по USB проверена на реальной плате: плата ESP32-C5 (4 МБ, USB-преобразователь CH340) прошита, считана побайтно, и прошивка запустилась. Ещё предстоит подтвердить: подключение и сканирование из Belksiri Scan на iPhone или iPad после этой установки.
  • Mac с Intel: подписана Developer ID и нотаризована Apple. Запускалась только через Rosetta на Mac с Apple silicon: на Mac с Intel не проверялась, установка по USB не проверялась.
  • Windows x64: не подписана (нет сертификата Authenticode). Собрана, проверена на имитируемых платах и запущена на Windows-машине GitHub Actions: на реальном ПК не проверялась, установка по USB не проверялась.
  • Язык утилиты: только английский, независимо от языка этой страницы. Поэтому названия, приведённые ниже, даны на английском, как на экране.

Требования

  • macOS 12 или новее либо Windows 10/11 x64.
  • Плата ESP32-C5 с флеш-памятью не менее 4 МБ. Любой другой чип, а также меньшая или нечитаемая флеш-память отклоняются до начала записи.
  • USB-кабель для передачи данных: многие кабели только заряжают.
  • Драйвер USB: для встроенного порта USB ESP32-C5 не нужен. Платам с преобразователем CP210x или CH340 драйвер производителя этого чипа нужен только в Windows.

Встроенная прошивка

ESP Device Studio 1.0.4 для ESP32-C5 (ESP-IDF v5.5.4). SHA-256 образа: 83de9994a710dba224c7ccb0248bb4e2334af38ce3e32e818c5d0cba66a9a499; утилита проверяет его перед записью. В комплекте — инструмент прошивки espflash 4.5.0 (лицензии MIT и Apache-2.0) без изменений.

Первое открытие приложения

Mac

  1. Откройте файл .dmg и перетащите Belksiri Firmware Installer в папку Программы.
  2. Откройте приложение и подтвердите: macOS спрашивает об этом один раз для загруженного приложения.

Windows

  1. Полностью распакуйте ZIP-файл (переносная версия, права администратора не нужны), затем запустите BelksiriFirmwareInstaller.exe.
  2. Поскольку файл не подписан, при первом запуске SmartScreen покажет предупреждение. Проверьте контрольную сумму, затем выберите «Подробнее» и «Выполнить в любом случае» только для этого приложения.

Установка прошивки

  1. Подключите плату ESP32-C5 к компьютеру USB-кабелем для передачи данных.
  2. Проверьте строку платы: ESP32-C5 (rev v1.0) · 4 MB flash Compatible. Если подключено несколько плат, выберите одну.
  3. Нажмите Install firmware и подтвердите.
  4. Дождитесь сообщения Firmware installed and verified. Не отключайте плату и не закрывайте окно во время операции.
  5. На iPhone или iPad откройте Belksiri Scan и подключитесь к плате по Bluetooth.

Что стирается: настройки, сохранённые на плате, включая её сеть Wi-Fi и пароль. Окно подтверждения напоминает об этом. «Verified» означает, что содержимое платы прочитано и совпадает с образом; подключение из Belksiri Scan затем подтверждает, что прошивка работает.

Если плата не отвечает

Удерживайте кнопку BOOT, нажмите и отпустите RESET, отпустите BOOT, затем нажмите Try again. При ошибке кнопка Copy details копирует отчёт, который можно приложить к письму на mboti.dev@gmail.com.
